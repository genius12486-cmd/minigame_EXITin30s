## 2. 제출용 필수 입력 항목 (과제 양식 복사용)

### 📌 재현·통과 확인 4가지
1. **어디로 가나요**:
   공개 배포 URL (GitHub Pages 링크)에 접속하여 [▶️ 게임 시작] 버튼을 누릅니다.
2. **무엇을 하나요 (3단계 이내)**:
   1) 방 우측의 [기계]를 클릭해 8개 버튼을 1번부터 시계 방향으로 돌려 토큰을 모으고, 시간이 부족하면 [시간 2초 늘리기]를 눌러 1토큰당 2초씩 생존 시간을 법니다.
   2) 왼쪽 [문]을 클릭하여 다이얼 숫자를 정확히 **5개**로 맞춘 후 [토큰 넣기]를 눌러 문을 엽니다. (5개가 아니면 토큰은 누적되지 않고 소멸)
   3) 열린 문 너머의 [축하방]으로 들어가 일지를 읽거나 숨겨진 상자를 열어 토큰을 획득한 뒤, 오른쪽 문의 암호(12개)를 풀어 복도로 나가 EXIT를 통해 진엔딩을 맞이합니다.
3. **무엇이 보이면 통과**:
   - **시간 초과(사망) 시**: 💨 이모지와 함께 "시간 초과" 모달이 뜨며, 보유하던 토큰은 상자에 보관됩니다.
   - **진엔딩 시**: 복도 끝 EXIT 클릭 시 "축하합니다! 진정한 탈출에 성공하였습니다." 모달이 뜹니다.
   - **일시정지**: 우측 상단 ⏸️ 버튼 클릭 시 화면이 어두워지며 타이머가 멈추고, [계속하기]를 눌러야 재개됩니다.
4. **안 될 때**:
   - 상단 우측 [🔄 초기화] 버튼을 눌러 로컬 저장소를 리셋하고 브라우저를 새로고침(F5)합니다.
