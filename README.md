# 방탈출 로그라이크 : 30초 안에 탈출하라

과제 2 : 내가 설계한 미니게임 제출 문서 및 검증 가이드

---

## 1. 게임 개요
- **장르**: 포인트 앤 클릭(Point-and-Click) 방탈출 & 로그라이크 & 미니게임
- **비주얼**: 직접 제작한 투명 스프라이트 에셋과 미니멀 테크 UI
- **실행 환경**: 데스크톱 웹 브라우저 (Chrome, Edge, Safari 등 무설치 실행)
- **조작 방식**: 100% 마우스 클릭 (8버튼 회전 채굴, 다이얼 투입식 문 개방, 빈 방의 버튼 등)

---

## 2. 제출용 필수 입력 항목 (과제 양식 복사용)

### 📌 재현·통과 확인 4가지
1. **어디로 가나요**:
   공개 배포 URL (GitHub Pages 링크)에 접속하여 [▶️ 게임 시작] 버튼을 누릅니다.
2. **무엇을 하나요 (3단계 이내)**:
   1) 방 우측의 [기계]를 클릭해 8개 버튼을 1번부터 시계 방향으로 돌려 토큰을 모으고, 시간이 부족하면 [시간 2초 늘리기]를 눌러 1토큰당 2초씩 생존 시간을 법니다.
   2) 왼쪽 [문]을 클릭하여 다이얼 숫자를 정확히 **5개**로 맞춘 후 [토큰 넣기]를 눌러 문을 엽니다. (5개가 아니면 토큰은 누적되지 않고 소멸)
   3) 열린 문 너머의 [축하방]으로 들어가 일지를 읽거나 숨겨진 상자를 열어 토큰을 획득한 뒤, 오른쪽 문의 암호(12개)를 풀어 복도로 나가 EXIT를 통해 진엔딩을 맞이합니다.
3. **무엇이 보이면 통과**:
   - **시간 초과(사망) 시**: 💨 이모지와 함께 "시간 초과" 모달이 뜨며, 보유하던 토큰은 상자에 보관됩니다.
   - **진엔딩 시**: 복도 끝 EXIT 클릭 시 "축하합니다! 진정한 탈출에 성공하였습니다." 모달이 뜹니다.
   - **일시정지**: 우측 상단 ⏸️ 버튼 클릭 시 화면이 어두워지며 타이머가 멈추고, [계속하기]를 눌러야 재개됩니다.
4. **안 될 때**:
   - 상단 우측 [🔄 초기화] 버튼을 눌러 로컬 저장소를 리셋하고 브라우저를 새로고침(F5)합니다.

### 📌 AI와 내 판단 3줄
1. **AI에게 맡긴 일**:
   과제 통과 기준(카드 1~5)에 맞춘 순수 HTML/CSS/JS 코드 구조 설계, Web Audio API를 활용한 무음원 사운드 합성, 기계 회전 완주 시 떠오르는 코인 파티클 애니메이션 구현, 다이얼식 정확한 5/12 토큰 문 개방 로직 작성.
2. **내가 판단한 일**:
   사물 확대 창에서 불필요한 제목 배너들을 완전히 제거하여 미니멀리즘 극대화, 시간 연장 밸런스를 1토큰당 2초로 최적화, 기계와 상자의 방 내 배치를 맞교환하여 동선 개선, 왼쪽 문을 단순 클릭이 아닌 '정확히 5개를 맞춰 넣어야 열리는 수수께끼식 다이얼'로 재설계하고 문 너머의 축하방에서 게임이 끝나지 않고 계속 이어지는 독창적인 엔딩 연출 기획.
3. **AI 말을 안 들은 일 (또는 제안을 수정한 이유)**:
   AI가 초기에 제안했던 단순 누적식 토큰 투입 및 즉시 게임 종료 방식은 퍼즐적 긴장감과 다회차 탐색의 묘미를 반감시킨다고 판단하여, 정확한 수량을 맞추지 못하면 토큰이 소멸되는 리스크 시스템과 클리어 메시지를 본 후에도 계속해서 진엔딩에 도전할 수 있는 자유 탐색 시스템으로 변경을 지시하였음.

### [카드 3] 난이도 값 단 1개 비교 검증 (20회 플레이)
* **단일 변경 수치**: 기계 1회 작동당 획득 토큰 수
  - **변경 전 (표준 모드)**: `NORMAL_TOKEN_PER_CLEAR = 2` (2개)
  - **변경 후 (시연용 모드)**: `DEMO_TOKEN_PER_CLEAR = 3` (3개)

#### 20회 플레이 비교 기록
* 화면 우측 상단 [📊 기록] 버튼을 누르면 인게임에서 직접 플레이한 20회 기록을 실시간으로 확인하고 텍스트로 추출할 수 있습니다.
* **최종 난이도 선택 이유**:
  - 2개 획득(표준)은 30초 동안 기계를 3회(6개) 가동하여 왼쪽 문(5개)을 열고 축하방까지 진입하기에 타이트하지만 성취감을 주는 난이도임.
  - 3개 획득(시연용)은 기계 2회(6개) 만에 문을 열 수 있어 시간적 여유가 있으며, 처음 플레이하는 유저도 쉽게 클리어할 수 있음.
  - 따라서 신규 유저의 진입 장벽을 낮추고 게임의 스토리를 온전히 즐길 수 있게 하는 **[시연용 모드(3개)]를 최종 추천 난이도로 선정함**.
