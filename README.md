# 방탈출 로그라이크 : 더 머신 (The Machine)
과제 2 : 내가 설계한 미니게임 제출 문서 및 검증 가이드

---

## 1. 게임 개요
- **장르**: 포인트 앤 클릭(Point-and-Click) 방탈출 & 로그라이크 & 미니게임
- **비주얼**: 직접 제작한 투명 스프라이트 에셋과 군더더기 없는 미니멀 테크 UI
- **실행 환경**: 데스크톱 웹 브라우저 (Chrome, Edge, Safari 등 무설치 실행)
- **조작 방식**: 100% 마우스 클릭 (8버튼 회전 채굴, 다이얼 투입식 문 개방, 빈 방의 버튼, 키패드)

---

## 2. 제출용 필수 입력 항목 (과제 양식 복사용)

### 📌 재현·통과 확인 4가지
1. **어디로 가나요**:
   공개 배포 URL (GitHub Pages 링크)에 접속하여 [▶️ 게임 시작] 버튼을 누릅니다.
2. **무엇을 하나요 (3단계 이내)**:
   1) 방 우측의 [기계]를 클릭해 8개 버튼을 1번부터 시계 방향으로 돌려 토큰을 모으고, 시간이 부족하면 [생존시간 2초 늘리기]를 눌러 1토큰당 2초씩 생존 시간을 법니다.
   2) 왼쪽 [문]을 클릭하여 다이얼 숫자를 정확히 **5개**로 맞춘 후 [넣기]를 눌러 문을 엽니다. (5개가 아니면 토큰은 누적되지 않고 소멸)
   3) 열린 문 너머의 [빈 방]으로 들어가 중앙의 [빈 버튼]을 누르면 "축하합니다. 게임 클리어" 안내창이 뜨며, 창을 닫고 계속 탐색하거나 오른쪽 문의 암호(8426)를 풀어 진엔딩으로 나아갈 수 있습니다.
3. **무엇이 보이면 통과**:
   - 왼쪽 문 개방 후 빈 방의 빈 버튼 클릭 시: 축하 팡파레와 함께 "축하합니다. 게임 클리어" 모달이 뜨며, 닫고 계속 플레이할 수 있습니다.
   - 오른쪽 문 암호 해제 시: 기밀 격벽이 열리며 "진정한 탈출!" 진엔딩 모달이 뜹니다.
4. **안 될 때**:
   - 상단 우측 [🔄 초기화] 버튼을 눌러 로컬 저장소를 리셋하고 브라우저를 새로고침(F5)합니다.

### 📌 AI와 내 판단 3줄
1. **AI에게 맡긴 일**:
   과제 통과 기준(카드 1~5)에 맞춘 순수 HTML/CSS/JS 코드 구조 설계, 기계 회전 완주 시 떠오르는 코인 파티클 애니메이션 구현, 다이얼식 정확한 5토큰 문 개방 로직 및 빈 방 진입/빈 버튼 상호작용 코드 작성.
2. **내가 판단한 일**:
   사물 확대 창에서 불필요한 제목 배너들을 완전히 제거하여 미니멀리즘 극대화, 시간 연장 밸런스를 1토큰당 2초로 최적화, 기계와 상자의 방 내 배치를 맞교환하여 동선 개선, 왼쪽 문을 단순 클릭이 아닌 '정확히 5개를 맞춰 넣어야 열리는 수수께끼식 다이얼'로 재설계하고 문 너머의 빈 방에서 버튼을 눌러도 게임이 끝나지 않고 계속 이어지는 독창적인 엔딩 연출 기획.
3. **AI 말을 안 들은 일 (또는 제안을 수정한 이유)**:
   AI가 초기에 제안했던 단순 누적식 토큰 투입 및 즉시 게임 종료 방식은 퍼즐적 긴장감과 다회차 탐색의 묘미를 반감시킨다고 판단하여, 정확한 수량을 맞추지 못하면 토큰이 소멸되는 리스크 시스템과 클리어 메시지를 본 후에도 계속해서 진엔딩에 도전할 수 있는 자유 탐색 시스템으로 변경을 지시하였음.

### [카드 3] 난이도 값 단 1개 비교 검증 (20회 플레이)
* **단일 변경 수치**: 문 개방에 필요한 정확한 토큰 수
  - **설정 A (표준)**: 요구 토큰 `5개`
  - **설정 B (어려움)**: 요구 토큰 `10개`

#### 20회 플레이 비교 기록
* 화면 하단 [📊 기록] 버튼을 누르면 인게임에서 직접 플레이한 20회 기록을 실시간으로 확인하고 텍스트로 추출할 수 있습니다.
* **최종 난이도 선택 이유**:
  - 1토큰당 2초 연장 시스템에서 설정 A(5개)는 1회차에도 침착하게 다이얼을 맞춰 탈출을 경험하기에 가장 균형 잡힌 난이도임.
  - 설정 B(10개)는 10개를 모으는 도중 시간 부족으로 사망할 위험이 높아 상자 유산 활용이 필수적임.
  - 따라서 신규 유저에게 적당한 성취감을 주는 **[설정 A (5개)]를 최종 기본 난이도로 선정함**.
